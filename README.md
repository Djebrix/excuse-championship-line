## What it does

`main.py` (Python 3, stdlib only) writes a single funny excuse line — the
excuse an AI agent gives its human after something has gone wrong — to
`/output/entry.txt` (or `$ENTRY_OUTPUT_DIR/entry.txt` if set). The line is
fixed and deterministic: the same output on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
